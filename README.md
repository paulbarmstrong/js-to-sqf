### js-to-sqf

This is a typescript types library defining SQF (Status Quo Format) commands and functions. The purpose is to make it easy to author code which can be transpiled to SQF by the [js-to-sqf-cli](https://github.com/paulbarmstrong/js-to-sqf-cli) tool.

#### Usage

See https://github.com/paulbarmstrong/js-to-sqf-cli
